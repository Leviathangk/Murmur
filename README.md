# Murmur

**用你自己的 API Key，在桌面上和各家大模型聊天。** 极简、原生、数据只留在本机。

DeepSeek、通义千问、Kimi、智谱 GLM、豆包、硅基流动、Claude、GPT、Gemini、OpenRouter、本地 Ollama 开箱即选；其他兼容 OpenAI 或 Anthropic 接口的服务也能接。

**[下载最新版](https://github.com/Qsnh/Murmur/releases/latest)** · macOS 12+ · Windows 10 / 11 · 安装包不到 10 MB

![Murmur](docs/screenshot.png)

## 适合你吗

| | |
|---|---|
| 系统 | macOS 12 及以上（Intel / Apple 芯片），Windows 10 / 11（x64 / ARM） |
| 模型 | 需要你自己的 API Key，或本机跑的 Ollama 等模型。Murmur 不提供模型 |
| 账号 | 不用注册、不用登录 |
| 隐私 | 对话和设置只存在本机；请求直接发到你填的接口地址，不经过中转，没有统计上报。打开联网搜索时，搜索词和要读的网址发给你选的搜索服务（TinyFish 或 Tavily）。每天到 GitHub 查一次有没有新版本，可以关掉 |
| 界面语言 | 简体中文、繁體中文、English，默认跟随系统 |

**能做的**

- 添加多个模型，随时切换
- 深度思考，可选低、中、高三档，实时显示思考过程
- 联网搜索、读网页（TinyFish 免费，也可用 Tavily），回答标注来源
- 发送图片，支持拖入和粘贴
- 发送 PDF、Word、Excel、PPT 等文件
- Markdown 渲染：代码高亮、表格、公式
- 预览回复里的 HTML 网页，下载为 .html 文件
- 对话自动保存，回复可复制、重新生成
- 从任意回复开分支对话
- 显示每条回复的 token 用量
- 搜索对话标题和内容
- 重命名对话，导出为 Markdown
- 系统提示词，网络代理
- 原生界面，启动快
- 浅色、深色外观，可跟随系统
- 界面支持简体中文、繁體中文和 English
- 关掉窗口后留在后台
- 自动检查并安装新版本
- 回复完成时发系统通知

**暂不支持**

- 读取文件里的图片，如扫描版 PDF
- 加密的 PDF
- 旧版 Office 格式（.doc、.xls、.ppt）和 WPS
- 插件、MCP 等工具调用
- 编辑已发送的消息
- 导入对话，多设备同步
- Linux、手机

## 下载安装

到 [Releases](https://github.com/Qsnh/Murmur/releases/latest) 下载对应的文件：

| 你的电脑 | 下载这个 |
|---|---|
| Mac（Intel 和 Apple 芯片通用） | `Murmur-<版本>-macos-universal.dmg` |
| 大多数 Windows 电脑 | `Murmur-Setup-<版本>-windows-amd64.exe` |
| ARM 处理器的 Windows（如骁龙笔记本） | `Murmur-Setup-<版本>-windows-arm64.exe` |
| Windows 免安装版 | `Murmur-<版本>-windows-{amd64,arm64}-portable.zip`，解压后运行 `Murmur.exe` |

安装包还没有开发者签名，第一次打开时系统会拦一下：

- **macOS**：提示无法打开时，到「系统设置 → 隐私与安全性」，在页面下方点「仍要打开」。如果提示「已损坏」，在终端执行 `xattr -dr com.apple.quarantine /Applications/Murmur.app` 后再打开
- **Windows**：SmartScreen 弹窗里点「更多信息」→「仍要运行」

从 0.7.0 起 Murmur 会自己检查和安装新版本，见下面的「怎么升级到新版本？」。macOS 上要先把 Murmur 拖进「应用程序」文件夹再打开，直接在安装镜像里打开的没法自动更新。

0.6.0 及更早的版本没有自动更新，要手动下载安装一次新版本。安装前先退出正在运行的 Murmur（关掉窗口它还在后台）：macOS 点菜单栏里的 Murmur 图标，Windows 右键通知区域里的 Murmur 图标，选「退出 Murmur」，否则安装时会提示文件正在使用。

## 三步开始

1. 打开 Murmur，点「添加模型」，选一个服务商，比如 DeepSeek
2. 填入 API Key，点「测试连接」，看到「连接成功」就可以了（Ollama 等本地模型不用填 Key）
3. 回到对话框输入问题，Enter 发送

服务商不在列表里？选「自定义」，填上接口地址和模型 ID。

## 常见问题

**关掉窗口后 Murmur 还在运行？**

是的，关掉窗口只是把它藏起来，Murmur 留在后台，下次打开不用重新加载。要彻底退出：

- **macOS**：点右上角菜单栏里的 Murmur 图标 →「退出 Murmur」，或在 Murmur 里按 ⌘Q。点图标 →「打开 Murmur」或点程序坞里的图标，窗口就回来了
- **Windows**：右键右下角通知区域里的 Murmur 图标 →「退出 Murmur」。单击图标打开窗口；图标被收进了「^」里的话，点开就能看到

Murmur 同时只运行一个：再次从启动台、开始菜单或桌面打开它，会直接把已经在运行的窗口叫出来。

**怎么升级到新版本？**

Murmur 每天到 GitHub 检查一次有没有新版本，有的话弹出「软件更新」窗口，列出这个版本更新了什么：

- 点「安装更新」，Murmur 下载新版本、校验签名后替换自己，完成后点「立即重新启动」；选「稍后」的话，下次打开 Murmur 时就是新版本
- 不想装这个版本，点「跳过这个版本」，有更新的版本时再提醒；点「稍后提醒我」明天再问
- 勾上「以后自动下载并安装更新」，之后的新版本在后台装好，Murmur 重新启动后生效（关掉窗口不算重新启动，要「退出 Murmur」后再打开）

想马上检查：「设置 → 通用 → 更新」里点「检查更新」；或者 macOS 点菜单栏里的 Murmur 图标、Windows 右键通知区域里的 Murmur 图标，选「检查更新…」；macOS 上还可以点屏幕左上角的「Murmur → 检查更新…」。不想自动检查，在「设置 → 通用 → 更新」里取消勾选「自动检查更新」。

检查和下载更新走「设置 → 通用 → 网络代理」里填的代理，连不上 GitHub 时填上代理再试。只下载版本信息和安装包，不上传任何数据。

提示「无法更新」：Murmur 没有权限替换自己所在的文件夹。macOS 上通常是直接在安装镜像（DMG）或「下载」文件夹里打开的，把 Murmur 拖进「应用程序」文件夹，再从那里打开；已经在「应用程序」里的，可能是当前账户不是管理员，换管理员账户更新，或者到 Releases 下载新版本手动安装；Windows 上请用安装程序安装，或者把免安装版解压到自己的文件夹（不要放在 `C:\Program Files` 下）。

**收不到回复的通知？**

- 正看着 Murmur 窗口时不发通知，回复就在眼前；点了「停止」的回复也不发
- 「设置 → 通用 → 通知」要勾上
- **macOS**：第一次发通知时系统会问是否允许，选了「不允许」的话，到「系统设置 → 通知 → Murmur」里打开
- **Windows**：到「设置 → 系统 → 通知」里看看通知是否打开
- 勿扰模式、专注模式下系统会把通知收起来，不弹出

**数据和 API Key 存在哪？**

只存在本机，文件仅当前用户可读：

- macOS：`~/Library/Application Support/Murmur/`
- Windows：`%AppData%\Murmur\`

`settings.json` 是模型和设置（API Key 以明文保存在这里），`updater.json` 是检查更新的选择，`chats.json` 是全部对话，`images/` 是对话里发送的图片，`documents/` 是发送的文件里读出的文字（原文件不复制；删除对话时这两样一起删除，从它开出的分支对话还在用的除外）。删掉这个文件夹就清空了所有对话和设置。

**导出的对话用什么打开？**

导出的是 Markdown 文件（`.md`），Typora、Obsidian、VS Code 等都能直接打开。对话里的图片放在旁边的 `<文件名>.assets` 文件夹里，移动文件时连同这个文件夹一起移动，图片才能正常显示；发送的文件导出的是读出的文字（如 `报告.pdf.txt`），也在这个文件夹里。思考过程和出错信息以引用的形式保留。

**发了图片，模型却说看不到，或者报错？**

模型本身要支持识图，比如 GPT-5、Claude、Gemini、通义千问 VL、GLM-4.5V、豆包视觉模型，以及 Ollama 里的 qwen2.5vl、llama3.2-vision 等。DeepSeek、Kimi K2 等纯文本模型不能看图，接口会报错，换一个支持识图的模型再「重新生成」即可。

超过 2048 像素的大图会先缩小再发送，手机照片会按拍摄方向摆正；支持 PNG、JPEG、GIF、WebP、BMP；暂不支持 HEIC，请先转换为 JPEG。

**发了文件，模型说没看到内容，或者答得不对？**

Murmur 在本机把文件转成文字，和你的问题一起发给模型，所以任何模型都能读，但只有文字：

- 点消息里的文件，看看读出来的文字对不对。扫描版 PDF 没有文字可读，添加时会提示；这种文件请截图后作为图片发送，并换一个支持识图的模型
- Word 读正文、标题、列表和表格（不含页眉页脚、批注）；Excel 每个工作表按 CSV 读出单元格的值，公式读的是上次保存时算出的结果，隐藏的工作表不读；PPT 按页读出文字
- 每个文件最多发送开头 10 万字，超出的部分不发送，添加时会提示。文件很长时，加上之前的对话可能超过模型能读的长度，接口会报错，开一个新对话再发

**回复下方的 token 用量怎么算的？看不到用量？**

用量是服务商在回复结束时返回的。输入包括系统提示词和之前的全部对话，所以对话越长，每次的输入越多；输出包括思考过程。

中途停止或出错的回复拿不到完整的用量，不显示；有些服务商或本地模型不返回用量，也不显示。

**预览网页要注意什么？**

- 预览用系统自带的网页引擎：macOS 上和 Safari 一样，Windows 上是 Edge 的 WebView2。Windows 11 自带 WebView2，Windows 10 一般随 Edge 装好；没有的话点「预览」直接在浏览器里打开
- 网页里的脚本会运行，引用的在线资源（如 CDN 上的 Tailwind、Chart.js）会联网加载；网页调不到 Murmur 本身，也打不开本机文件
- 点网页里的链接会在浏览器中打开，预览留在原处；关掉预览，网页就停止运行
- 代码块写完才能预览和下载：还在生成的要等它写完；回复被截断、代码块没有写完的预览不了，让模型接着写完整再试

**怎么切换界面语言？**

在「设置 → 通用 → 语言」里选，立即生效。默认「跟随系统」：按系统设置里的首选语言显示，系统用的不是中文或英文时显示英文。

软件更新窗口要退出 Murmur 再打开后才换成新的语言。更新说明目前只有中文。

**连不上或者报错？**

在「设置 → 模型」里点「测试连接」，会显示具体的错误。先检查接口地址、API Key 和模型 ID；需要代理才能访问的服务，在「设置 → 通用 → 网络代理」里填上代理地址。

**打开了深度思考，却看不到思考过程？**

首先模型本身要支持思考。各家打开思考的参数不一样，Murmur 默认按接口地址自动识别；识别不对时，在「设置 → 模型 → 思考参数」里手动选：

| 思考参数 | 适用于 |
|---|---|
| `reasoning_effort` | OpenAI、Ollama、Gemini |
| `enable_thinking` | 通义千问、硅基流动 |
| `thinking.type` | 智谱 GLM、DeepSeek、豆包 |
| `reasoning` | OpenRouter |
| 不发送 | Kimi K2 Thinking、DeepSeek Reasoner 等总会思考的模型 |

Anthropic 协议的模型不用选，Murmur 会自动处理。

**怎么联网搜索？**

1. 选一个搜索服务，注册拿 API Key：
   - [TinyFish](https://agent.tinyfish.ai/api-keys)（默认）：免费，不用绑卡，Key 以 `sk-tinyfish-` 开头。每小时可以搜 500 次，每天可以读 1000 个网页
   - [Tavily](https://tavily.com)：Key 以 `tvly-` 开头，每月免费 1000 次额度，搜一次用 1 次，每读 5 个网页用 1 次。每条搜索结果带的正文比 TinyFish 长
2. 在「设置 → 对话 → 联网搜索」里选好服务、填上 Key，点「测试搜索」，看到「可以搜索」就好了。两个服务的 Key 分开保存，切换不用重填
3. 点输入框下方的「联网搜索」打开，再点一次关闭

打开后，由模型自己判断要不要搜、搜什么：问最新的消息、价格、版本这类问题时它会去搜，一条回复最多搜 5 次；问数学、写代码这类不需要的就直接回答。搜索结果只有一小段摘要，不够用时模型会打开网页读全文，一条回复最多读 5 个网页；你在消息里贴了网址，它也会去读。模型只能读搜到的网页和你给的网址，免得网页里的文字诱导它把对话内容发到别的网站。

- 回复按发生的顺序显示每一步：「已思考 3 秒」→「已搜索「Go 1.27」· 10 个网页」→「已读取「Go 1.27 is released」」→「已思考 2 秒」→ 回答。每次思考、搜索、读网页各占一行，点开看思考内容、这次搜到的带编号的网页（标题、网站、日期），或读的是哪个网页，点标题在浏览器中打开。回答里的 [1]、[2] 就对应这些编号，可以逐条核对
- 搜索或读网页出错（Key 无效、额度用完、连不上、网页不存在、网站拦截）时，这一步显示为红色的「搜索「…」失败」「读取「…」失败」，点开看原因；模型也会收到失败原因，一般会换个网页或说明没查到
- 模型要支持工具调用（function calling）才能自己决定搜索、读网页。不支持的模型（如一些本地小模型），Murmur 会先用你的问题搜一次，把结果和问题一起发给它，这时不会读网页
- 搜索词和要读的网址发给你选的服务，走「设置 → 通用 → 网络代理」；国内连不上时填上代理
- 搜到的摘要和读到的网页正文会作为输入发给模型（每个网页最多 1 万字），所以联网时输入的 token 会多一些
- 导出对话时，来源列在回复后面

**思考深度的低、中、高有什么区别？**

点输入框下方的「深度思考」选择档位。档位越高，模型想得越久、越仔细，回复也越慢、用的 token 越多；简单的问题用「低」就够了。思考参数是「不发送」的模型由模型自己决定想多久，档位不起作用。
